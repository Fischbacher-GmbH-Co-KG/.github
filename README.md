# .github
Fischbacher ist ein traditionsreiches Münchner Unternehmen für Baumaschinen, Bauaufzüge und professionelle Baustellentechnik. Das Unternehmen verbindet Verkauf, Vermietung, Ersatzteilversorgung sowie Reparatur- und Wartungsleistungen und richtet sich vor allem an Bauunternehmen, Handwerksbetriebe und weitere gewerbliche Fachkunden.
